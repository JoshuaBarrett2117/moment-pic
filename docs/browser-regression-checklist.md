# 浏览器回归清单

日期：2026-04-17
执行者：Codex

## 使用方式

本清单用于本地浏览器回归验证，优先覆盖移动端、小屏设备与高频主路径。

建议至少验证以下环境：

- 桌面端：Chrome 最新版，宽度 >= 1440px
- 平板端：宽度 768px 左右
- 手机端：宽度 390px 左右

## 1. 登录页

- 页面首屏无乱码，标题、副标题、说明文案均为正常中文
- 输入账号与密码后可正常登录
- 登录按钮在加载中有明确反馈
- 错误提示可见且不挤压主要输入区域
- 小屏下卡片不超出屏幕，底部说明不会被裁切

## 2. 图库页

- 侧边栏在桌面端固定显示，移动端可正常打开和关闭
- 移动端顶部标题区不会遮挡首行内容
- 筛选面板在移动端可展开、收起
- 搜索框、来源、排序、每页数量均可点击
- “清空筛选”后恢复默认值
- 空状态文案与图标显示正常
- 卡片在桌面端 hover 动效轻微，不出现明显抖动
- 卡片删除按钮在移动端可见，在桌面端 hover 后可见
- 删除图集弹层文案正常，按钮间距合理
- 分页区在小屏不拥挤，可点击上一页、下一页与页码

## 3. 相册详情页

- 从图库进入详情后，页面标题与返回按钮显示正常
- 小屏底部栏不遮挡图片网格内容
- 图片删除按钮在移动端可见
- 删除图片弹层文案正常，点击区域足够大
- 加载更多时底部触发区域正常工作
- 错误态下“重试”按钮可点击

## 4. 图片查看器

- 打开大图后默认可看到关闭按钮、页码与提示
- 移动端提示会自动消失，但再次点按图片能显示控制条
- 左右滑动可切换图片
- 关闭按钮在带安全区的设备上不会贴边
- 底部工具条不被系统手势区域遮挡
- 缩放、旋转、重置均可正常使用

## 5. 设置页

- 基础设置与高级设置切换正常
- 小屏下顶部导航不拥挤，可横向滚动
- 输入数字后失焦可触发自动保存
- “正在保存 / 已自动保存 / 保存失败”状态文案正常切换
- 添加目录、编辑目录、删除目录按钮都可点击
- 长页面滚动到底部时，最后一项不被底部安全区遮挡

## 6. 重点观察项

- 是否仍存在乱码文本
- 是否存在固定栏遮挡正文
- 是否有按钮点击区域过小
- 是否有弹层在移动端贴边过近
- 是否有 hover 动效在桌面端显得过强
